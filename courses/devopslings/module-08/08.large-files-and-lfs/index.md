---
kind: lesson
title: "nine minutes to clone 200 KB of python"
description: |
  A six-megabyte sprite atlas is regenerated every sprint and committed whole,
  and random binary data does not delta-compress: every revision sits in the
  history at full size and every clone transfers all of them. Deleting the file
  leaves the objects exactly where they were. The grader clones the origin the
  way a build machine would and requires a history under 1 MB with the atlas
  still at the tip, byte for byte, fetched through LFS.
name: large-files-and-lfs
slug: large-files-and-lfs
createdAt: "2026-08-31"

sandbox:
  stack: git-box
  service: box

tasks:
  init_scenario:
    init: true
    timeout_seconds: 300
    run: |
      set -e

      rm -rf ./* ./.[!.]* 2>/dev/null || true

      mkdir -p remotes
      git init -q --bare remotes/app.git
      git -C remotes/app.git symbolic-ref HEAD refs/heads/main

      root=$(pwd)
      build=$(mktemp -d)
      trap 'rm -rf "$build"' EXIT

      git init -q "$build"
      git -C "$build" config user.email dev@example.com
      git -C "$build" config user.name 'Dev'

      mkdir -p "$build/src" "$build/assets"

      cat > "$build/src/render.py" <<'F'
      # The renderer loads the packed sprite atlas next to it.
      ATLAS = "assets/render.bin"

      def load():
          with open(ATLAS, "rb") as f:
              return f.read()
      F

      cat > "$build/README.md" <<'F'
      # sprite-tool

      The atlas in assets/ is regenerated by the art pipeline every sprint and
      committed here so the renderer builds without the pipeline.
      F

      git -C "$build" add -A
      git -C "$build" commit -q -m 'c0: sprite-tool'
      git -C "$build" branch -M main

      revision() {
          head -c 6000000 /dev/urandom > "$build/assets/render.bin"
          git -C "$build" add -A
          git -C "$build" commit -q -m "$1"
      }

      revision 'assets: atlas rebuild, sprint 11'

      echo '# sprint 12: add the shadow pass' >> "$build/src/render.py"
      git -C "$build" add -A
      git -C "$build" commit -q -m 'render: shadow pass'

      revision 'assets: atlas rebuild, sprint 12'

      echo '# sprint 13: pack the ui sprites' >> "$build/src/render.py"
      git -C "$build" add -A
      git -C "$build" commit -q -m 'render: pack ui sprites'

      revision 'assets: atlas rebuild, sprint 13'

      sha256sum "$build/assets/render.bin" | cut -d' ' -f1 > "$root/.expected-asset-sha256"

      git -C "$build" remote add origin "$root/remotes/app.git"
      git -C "$build" push -q origin main
      git clone -q "$root/remotes/app.git" app
      git -C app config user.email dev@example.com
      git -C app config user.name 'Dev'

      rm -rf "$build"
      cat > questions.txt <<'Q'
      Cloning sprite-tool takes nine minutes on the office connection, and the
      repository is 200 KB of Python. The rest is assets/render.bin: the art pipeline
      regenerates a six-megabyte sprite atlas every sprint and it has been committed
      each time, whole. Random binary data does not delta-compress, so the history
      carries every revision at full size, and a clone pays for all of them:

          du -sk app/.git/objects

      The tip only needs the current atlas. The three that came before it are being
      transferred to every developer and every build, forever.

      Make a fresh clone of remotes/app.git carry less than 1 MB of git history, with
      assets/render.bin still present at the tip and byte for byte what it is now.

      Deleting the file in a new commit is the answer that does not work — it takes
      the atlas off the tip and leaves all four revisions reachable in the history.

      The grader clones remotes/app.git with --no-local (a clone from a path on the
      same disk copies the object store wholesale, which would measure nothing) and
      checks the size of the history, the sha256 of the atlas, and that it arrives
      through LFS.
      Q

      echo "scenario ready — app/ cloned; .git/objects is $(du -sk app/.git/objects | cut -f1) KB"

  verify_done:
    needs: [init_scenario]
    timeout_seconds: 300
    run: |
      set -e

      root=$(pwd)
      limit_kb=1024

      if [ ! -d remotes/app.git ] || [ ! -s .expected-asset-sha256 ]; then
        echo "not yet: remotes/app.git or .expected-asset-sha256 is missing. The grader"
        echo "         clones the origin the way a new machine would."
        exit 1
      fi
      want=$(cat .expected-asset-sha256)

      work=$(mktemp -d)

      # --no-local matters: a clone from a path on the same filesystem copies the
      # object store wholesale, dead objects included, and would report the size of
      # the origin's disk rather than of a real fetch. The transport a colleague or a
      # build machine uses only ever sends reachable objects.
      if ! git clone -q --no-local "$root/remotes/app.git" "$work/fresh" 2>"$work/err"; then
        # A clone that dies in the smudge filter is a specific mistake, not a
        # broken remote: the pointers were pushed and the objects were not.
        if grep -qE 'smudge|remote missing object|lfs' "$work/err"; then
          echo "not yet: the clone fetched the history and then failed to materialise"
          echo "         assets/render.bin: the LFS store on the remote has no object for"
          echo "         the pointer the tip records. The pointer travels with the commit;"
          echo "         the bytes only travel on a push that carries them —"
          echo "         git lfs push --all origin main."
          exit 1
        fi
        echo "not yet: cloning remotes/app.git failed:"
        tail -5 "$work/err" | sed 's/^/         /'
        exit 1
      fi

      hist=$(du -sk "$work/fresh/.git/objects" | cut -f1)
      asset="$work/fresh/assets/render.bin"
      lfs_listed=$(git -C "$work/fresh" lfs ls-files 2>/dev/null | grep -c 'assets/render.bin' || true)

      if [ ! -f "$asset" ]; then
        echo "not yet: a fresh clone has no assets/render.bin. Removing the file in a new"
        echo "         commit takes it off the tip and leaves every earlier revision of it"
        echo "         in the history — the clone still transfers ${hist} KB. The atlas has"
        echo "         to still be there at the tip, out of the history."
        exit 1
      fi

      got=$(sha256sum "$asset" | cut -d' ' -f1)
      if [ "$got" != "$want" ]; then
        if head -c 40 "$asset" | grep -q 'git-lfs.github.com/spec'; then
          echo "not yet: assets/render.bin in a fresh clone is still the pointer file — the"
          echo "         clone had nowhere to fetch the object from. A pointer is what git"
          echo "         stores; the bytes live in the LFS store on the remote, and they get"
          echo "         there on push: git lfs push --all origin, or push the rewritten"
          echo "         branch so the objects go with it."
          exit 1
        fi
        echo "not yet: assets/render.bin at the tip is not the atlas that was committed"
        echo "         (sha256 $(printf '%s' "$got" | cut -c1-12), expected $(printf '%s' "$want" | cut -c1-12))."
        echo "         The history has to get smaller without the asset changing."
        exit 1
      fi

      if [ "$lfs_listed" -eq 0 ]; then
        local_lfs=$(git -C app lfs ls-files 2>/dev/null | grep -c 'assets/render.bin' || true)
        if [ "$local_lfs" -gt 0 ]; then
          echo "not yet: your app/ has the atlas under LFS and the clone of remotes/app.git"
          echo "         does not. A history rewrite gives every commit a new id, so the"
          echo "         branch cannot fast-forward: git push --force origin main."
          exit 1
        fi
        echo "not yet: in a fresh clone assets/render.bin is still an ordinary git blob"
        echo "         and the history is ${hist} KB. Every sprint's atlas is still in"
        echo "         there at full size: git packs each revision whole, because"
        echo "         regenerated binary data has nothing to delta against. Converting"
        echo "         the tip alone would not help — the earlier revisions are what the"
        echo "         clone is paying for."
        exit 1
      fi

      if [ "$hist" -gt "$limit_kb" ]; then
        echo "not yet: the atlas is under LFS at the tip, and a fresh clone still transfers"
        echo "         ${hist} KB of history (the target is under ${limit_kb} KB). Tracking a"
        echo "         path only changes what happens to future commits; the blobs already"
        echo "         committed stay reachable until the commits themselves are rewritten:"
        echo "         git lfs migrate import --everything --include='assets/*.bin'."
        exit 1
      fi

      echo "PASS — a fresh clone carries ${hist} KB of history instead of the 17 MB it"
      echo "       started at, and assets/render.bin still arrives byte for byte, fetched"
      echo "       from the LFS store rather than replayed from every commit that touched"
      echo "       it."
