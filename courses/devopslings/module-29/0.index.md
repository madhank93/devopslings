## What you'll be able to do

- Create spans by hand with the OpenTelemetry SDK, and give them the status,
  kind, name and semantic-convention attributes every tool downstream reads
- Find what zero-code instrumentation does not see, and carry context across
  threads, queues, batches and services with the right propagator
- Keep tenant data in baggage away from third parties, and link a batch to
  every message in it
- Read an N+1, a critical path and a skewed clock straight off a trace
- Choose between head, parent-based and tail sampling, and run tail sampling
  across more than one gateway Collector
- Size a Collector that sheds load instead of crashing, and pick OTLP over
  gRPC or HTTP
- Build RED metrics and a service map from spans, name database queries in
  spans, and group exceptions into issues
- Triage a slow request from metric to trace to profile, and tell server time
  from what the user waited
- Decide agent versus gateway, set an observability cost budget, write an
  instrumentation standard, and migrate off a vendor agent without going dark

## The sandbox

The same `obs-stack` as modules 18 and 19: Prometheus, Grafana, Loki, Tempo,
an OpenTelemetry Collector, and services that trace. checkout, fulfil and
ledger are the services most lessons rewrite, each a single Python file
using the OpenTelemetry SDK or run under `opentelemetry-instrument`. One
lesson adds `db-stack`'s Postgres, a few add a second gateway Collector, and
the triage drill adds Pyroscope.

You work in the `box` container. Everything you edit is under `/obs`:

| Path | What |
|---|---|
| `/obs/apps/*.py` | the services' source; saving a file restarts that service |
| `/obs/otel/collector.yaml` | the Collector's config; saving it restarts the Collector |
| `/obs/logs/*.log` | each service's output, the Collector's included |
| `/obs/answers/` | written answers the checks read |

Tempo answers on `http://tempo:3200` from the box, and its TraceQL search is
at `/api/search`. From your browser: Grafana at <http://localhost:13000> has
Prometheus, Loki and Tempo datasources, and Tempo is at
<http://localhost:13200>.
