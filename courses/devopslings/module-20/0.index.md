## What you'll be able to do

- Compute percentiles by hand, and say what each one does and does not tell
  you about the users behind it
- Aggregate latency across instances correctly, from histogram buckets
- Load-test with an open model, choose the test shape that finds a given
  failure, and make the test's exit code a deploy gate
- Use fan-out arithmetic, Little's Law and the Universal Scalability Law to
  size a system before you run it, then confirm the size by running it
- Find the hot path in a profile, and benchmark a fix so the result repeats
- Replace a resource alert with one that fires on harm to users

## The sandboxes

Two of them. The percentile and alerting lessons use `obs-stack` from module
18: Prometheus, Loki and Grafana, worked from the `box` container. The load
and scalability lessons use `chaos-stack` from module 21: each lesson deploys
its own small service into the `checkout` container and drives it with k6.
For those, you work on the host in `sandboxes/chaos-stack`, and your files go
in its `answers/` directory.

## Before you start

Module 18 for PromQL and histograms, and module 21 for k6 and the
chaos-stack.
