## What you'll be able to do

- Say where a file a container wrote actually lives, and get it out two ways
- Explain why `docker stop` sometimes takes exactly ten seconds, and fix it
- Order a Dockerfile so the cache does what you wanted, and cut image size with
  a multi-stage build
- Debug service-to-service networking in compose from first principles

## How these run

Unlike module 01, these lessons have no pre-built sandbox. You are writing
Dockerfiles and compose files, so the thing under study is the build itself —
starting a stack first would be backwards. Each lesson gives you a scratch
working directory under `scratch/<lesson>/` and the checks run against what you
built there.

`devopslings shell <lesson>` drops you into that directory.
